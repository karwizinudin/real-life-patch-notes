## The entry

`main.py` writes one patch note to `/output/entry.txt`:

> v2.1.3: fixed a bug where the brain replayed your most embarrassing moment from 2014 at 3 a.m. with no skip button.

Run it with `python3 main.py`. It validates the line first (1–160 characters, single line, not blank) and writes it byte-identically on every run.
